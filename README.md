## 📝 How I Work

> **구현 → 확인 → 원인 분석 → 해결 → 기록**

- 동작 결과뿐 아니라 **왜 그렇게 동작하는지** 확인합니다.
- 문제가 생기면 한 번에 바꾸기보다 원인을 나누어 검증합니다.
- 팀 프로젝트에서는 제 담당 영역뿐 아니라 **DB · Backend · Frontend 사이의 연결 지점**까지 확인합니다.
- 학습 내용과 시행착오를 README와 Notion에 지속적으로 기록하고 있습니다.
